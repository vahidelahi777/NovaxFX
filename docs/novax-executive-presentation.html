The Problem We Solve

Most algorithmic trading platforms fail for the same reason:
they confuse in-sample Sharpe ratios with real edge.

A strategy that works on the data you used to develop it is not a strategy — it is memorisation.
  • Run 100 backtests, pick the best → curve-fitted noise
  • Report the best trial's Sharpe, ignore the rest
  • Live performance always disappoints
  • The "edge" was never real — it was selection bias
Industry failure rate
~80%
Of retail algo strategies fail to reproduce in live trading
Root cause
Overfitting + multiple-testing bias
No penalisation for the number of strategies tested
Our answer
Make overfitting structurally impossible
Deflated Sharpe · Lockbox · Artifact trail — all enforced by code

Research Integrity Layer

Three structural guarantees that no competitor enforces

🔬
Deflated Sharpe
Every trial you ran penalises the Sharpe you report. Run 50 strategies, your reported Sharpe is corrected downward — automatically. A 3.0 in-sample becomes ~0.8 deflated after 47 trials.
🔒
One-Shot Lockbox
The out-of-sample window is sealed until all decisions are frozen. Opening it twice is structurally impossible — it's a single-call function that records its own opening to the artifact trail.
📋
Artifact Trail
Every backtest is hash-addressed and logged before it runs. If it crashes mid-run, the log still records the attempt. No hidden experiments. No cherry-picking.
These are not guidelines. They are enforced by code. A caller cannot bypass the lockbox. The gate reads from artifacts, not from values the caller supplies. Capital will not be risked until all gates pass.
